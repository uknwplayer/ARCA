# Contributing to ARCA

ARCA welcomes reproducible contributions to source code, tests, schemas, documentation, adapters, and execution providers.

## Before opening a pull request

- keep changes narrowly scoped;
- add or update tests for behavioral changes;
- do not commit secrets, private keys, credentials, personal data, private investigation material, or operational runtime state;
- preserve the distinction between capability, trust, admission, authorization, and execution;
- do not introduce arbitrary remote shell execution as a convenience layer;
- keep public workflows least-privileged and safe for untrusted pull requests.

## Contributions

By intentionally submitting a contribution for inclusion in ARCA, you agree that the contribution is provided under the repository's Apache License 2.0 unless explicitly stated otherwise for a separately identified third-party component.

A successful test run does not by itself authorize promotion into a protected ARCA Core release.
