# ARCA Controlled Investigative Pilot V0.1

Status: PROPOSED — Roadmap 15/16

This pilot is deliberately synthetic and non-adverse. It exercises the complete investigative control path without naming a real target or downloading/storing raw evidence.

It validates: acquisition boundary; Evidence Taxonomy; CTG; source-backed corpus; pattern analyst; public-data planning; Public-Record Watcher contract; temporal/relational analysis; Red-Flag Engine; autonomous private case candidate; four-child Mesh006 mission construction; adversarial verification; private Investigation Record; and reviewed case-learning admission.

The CI executes `scripts/validate-investigative-roadmap.py`. This is an integration/control-plane proof, not a claim that a live real-world investigation or live satellite mission has been completed.

Public ARCA contains the pilot and CI. No private case data or raw artifact is created.
