# ADR-ARCA-0005 — Estados epistêmicos qualitativos

**Status:** aceito provisoriamente  
**Decisão:** o Core usa estados qualitativos controlados e não calcula porcentagem de verdade.

## Estados

`Confirmado`, `Provável`, `Possível`, `Não verificado`, `Contradito`, `Desconhecido`.

Qualquer métrica numérica futura deverá declarar fórmula, calibração, domínio, erro e limitação; nunca poderá ser apresentada automaticamente como probabilidade empírica.
