# AIE D2 Human Review / Answer-Key Gate V0.1

The D2 blind-evaluation path keeps detector outputs separate from independent human review.

The reader strips answer-key, finding, profile and label fields before presenting samples. The review template binds review to the exact corpus fingerprint. The answer-key compiler accepts only complete coverage, explicit rationale, sample-bound public evidence references and detector IDs from the committed detector catalogue.

Expected detector IDs mean signals that should be surfaced for review. They do not encode fraud, guilt or illegality.

This gate is evaluation infrastructure. It does not publish person-specific conclusions or bypass the investigative evidence taxonomy.
