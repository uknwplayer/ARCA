# Investigative Mesh006 Live Gate V0.1

This gate is the operational proof for the public/sanitized investigative Mesh006 path.

A manual canonical workflow dispatches four bounded public child tasks across Satellite A and Satellite B:

1. public-source normalization;
2. abstract trace extraction;
3. source-locator structural verification;
4. typology matching.

The queue V0.2 carries only a bounded JSON task input. Secret-like keys/credential material are rejected before dispatch. No raw investigative artifact or case-sensitive record is permitted. Satellite execution performs deterministic local transformations only; it does not fetch private data or make adverse findings.

Success requires four ACCEPTED child receipts, two independently addressable satellite execution domains, a deterministic mission receipt/aggregate hash, and observed cross-domain workflow overlap. A typology match remains explicitly `match_is_finding=false`.

The dispatch token is control-plane authentication only and is never included in the public queue envelope or proof artifact.
