# ARCA Temporal & Relational Analysis V0.1

Status: PROPOSED — Roadmap 9/16

Provides deterministic primitives for ordering sourced events and representing sourced relationships without converting temporal proximity or graph proximity into causation.

Every event/edge must carry provenance references. Derived relations are labelled as observed, inferred-for-review, or contradicted. A time-window coincidence may generate a verification question but never an automatic finding.

Public ARCA stores generic graph/timeline code and synthetic tests. Real case timelines, named nodes, edges and locators remain private investigative data. Raw artifacts remain outside repositories.
