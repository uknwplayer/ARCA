# ARCA Autonomous Network and Human Participation V0.1

Status: **FOUNDATION**

## Decision

ARCA is autonomous by default and participatory by interface.

The national observatory may create work from public-source changes, scheduled review and bounded anomaly leads without waiting for a human request. Humans may request, follow, enrich, dispute and audit investigations, but comments or confirmations do not become evidence automatically.

Durable autonomy belongs to the event queue, investigation state and custody records. Workers may sleep when no task is pending and wake from events; autonomy does not require every process to run continuously.

## National scope

The operating scope is Brazil. Barueri remains the first test origin and an optional local enrichment profile, not the default or permanent limit.

The same jurisdiction contract applies to:

- national and federal sources;
- all 26 states and the Federal District;
- every municipality addressable through a jurisdiction profile;
- PNCP as a national source;
- official state and municipal portals as complementary sources.

## Shared investigations

A canonical investigation key is derived from jurisdiction, subject reference, topic, time window and source scopes.

Concurrent humans requesting the same investigation join one shared mission. The scheduler scales workers from pending work and task classes, not from connected-user count.

Ten users viewing or requesting the same canonical target therefore create:

- one investigation;
- one durable evidence/provenance history;
- multiple subscribers and contributors;
- new worker demand only when a distinct source, dispute, deepening request or other actionable trigger appears.

Distinct targets may create distinct queued missions and execute in parallel within policy, budget and capacity.

## Human participation

Humans may:

- observe and subscribe;
- submit a public source;
- comment without mutating canonical evidence;
- provide a confirmation that remains a review event, not proof;
- dispute an interpretation and reopen adversarial review;
- request bounded deepening;
- perform explicit human review;
- audit provenance, receipts and state transitions.

No user receives authority to silently rewrite evidence history or bypass custody, privacy, adversarial review or publication gates.

## Public lifecycle

`LEAD -> TRIAGE -> COLLECTION -> ANALYSIS -> ADVERSARIAL_VERIFICATION -> HUMAN_REVIEW`

Human review may resolve into `PUBLICABLE`, `INCONCLUSIVE`, `REFUTED` or `ARCHIVED`. Reopening paths preserve prior state and provenance.

`PUBLICABLE` requires explicit human review. A red flag, typology match, comment, vote, confirmation count or successful executor receipt is not by itself an adverse finding.

## Mural boundary

The public mural may display:

- mission activity and current evidence state;
- lawful public-source locators;
- reviewed derived facts and relationships;
- unresolved hypotheses, gaps and disputes;
- requests for public-source assistance;
- execution and integrity receipts;
- reviewed publication outcomes.

It must not expose raw investigative artifacts, private case records, credentials, operational secrets or automatic person-specific accusations.

## Interface surfaces

The eventual human interface is organized into:

1. **Mural** — reviewed public network activity;
2. **Explore** — national search by jurisdiction, public body, entity, contract, period or topic;
3. **Investigations** — a shared mission workspace with evidence state, provenance, timeline, gaps and disputes;
4. **Queue** — transparent submitted leads, duplicate grouping, priority reason and mission state.

This foundation defines routing and state contracts only. It does not launch a real investigation, publish a finding or provision the private investigative backend.
