# ARCA Red-Flag Engine V0.1

Status: PROPOSED — Roadmap 10/16

Evaluates derived observations against admitted defensive typology indicators. Output is a set of traceable red-flag matches plus verification questions — never a person/entity risk score or wrongdoing probability.

Each match requires typology id, red-flag id/text, matched trace, provenance references and at least one verification question. Contradictory evidence references can be attached and must not be discarded.

The engine does not rank people, companies or political actors. It does not infer guilt and cannot auto-publish adverse conclusions.

Public ARCA stores rules/engine/tests. Concrete matches remain private investigative records.
