# ARCA Investigative Mesh006 Integration V0.1

Status: PROPOSED — Roadmap 12/16

Maps one bounded investigative mission into independent public child jobs for Mesh006 fan-out/fan-in.

Only **public, secret-free, non-case-sensitive payload classes** may use public execution satellites. Case-specific private records remain outside public queue payloads. Children carry task references/identifiers, not raw source files.

Allowed V0.1 task classes: public-source normalization, abstract trace extraction, source-locator verification, and typology matching over explicitly public/sanitized inputs.

Mission fan-in accepts only Mesh004 `ACCEPTED` child receipts through existing Mesh006 receipt logic. A successful executor result is execution evidence, not investigative truth; Evidence Taxonomy still governs claims.

Public ARCA stores orchestration code/tests. Private case state stays private. Raw artifacts/secrets go to neither public queue nor repositories.
