# Public Source Resolver V0.1

The resolver combines facts already obtained from lawful public sources without converting disagreement into certainty.

It preserves per-source provenance, records adapter failures, and marks conflicting values as `CONFLICT`. The PNCP adapter consumes public PNCP-derived facts. Municipality adapters are keyed by IBGE code, while municipality-specific source profiles remain outside the generic public core unless separately approved for publication.

A resolver result is evidence-routing metadata, not a finding of wrongdoing. Source acquisition remains subject to the Investigative Boundary, and adverse conclusions remain subject to evidence classification and human review.
