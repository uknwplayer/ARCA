# ARCA Anti-Corruption Pattern Analyst V0.1

Status: PROPOSED — Roadmap 6/16

A bounded analytical worker that compares **derived public-record observations** with admitted CTG/corpus patterns and emits review leads.

It may: normalize observations, identify trace matches, cite typology/source ids, formulate verification questions, and emit an `UNRESOLVED` analytical lead for Evidence Taxonomy processing.

It may not: declare guilt/corruption, assign guilt probability, expand acquisition authority, fetch private data, publish person-specific adverse conclusions, self-admit new typologies, or persist raw artifacts.

A match must include observed trace ids, typology id, verification questions, and provenance references. No match is a finding.

Public ARCA stores worker code/contracts/tests. Concrete worker outputs about real cases belong only in private investigative storage.
