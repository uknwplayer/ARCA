# ARCA Investigation Layer

This directory contains **public, generic investigative knowledge** only: reviewed defensive typologies and public source descriptors.

Case-specific investigative data does not belong here. Real Investigation Records, named relationships, case source locators and evidence assessments require the designated private investigative store.

Raw source files and secrets are not repository content.

See `docs/ARCA_INVESTIGATIVE_ROADMAP_V0_1_VALIDATION.md` for the complete V0.1 boundary and validation chain.
