# Security Policy

ARCA is security-sensitive infrastructure. Please do not publish suspected vulnerabilities, credentials, private keys, access tokens, private investigation material, or exploit details in public issues.

## Reporting

Use GitHub's private security-advisory mechanism for the public ARCA repository when available. If that channel is unavailable, contact the maintainers through a private channel listed by the repository owner.

## Scope

A security report should identify the affected version or commit, the impacted component, reproducible conditions, and the minimum information needed to validate the issue. Do not include third-party secrets or personal data.

## Operational separation

The open-source repository must not contain production credentials, private investigation state, live federation mailboxes, private connector state, or operational key material.

Security reports do not grant authority to bypass ARCA admission, policy, human-review, or publication boundaries.
